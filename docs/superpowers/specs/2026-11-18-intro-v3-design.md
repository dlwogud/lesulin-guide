# 시작 화면 v3 + 지도 화면 디자인 언어 맞추기 — 설계

2026-11-18 · 최종발표 11/25 · 참고 디자인: claude.ai 아티팩트 "르슐랭 인트로 / Style guide v3"
(남이 만든 공개 페이지 — 디자인 참고로만 씀)

## 왜

사용자가 새 디자인(v3)을 가져와 "이 디자인으로, 기능 빠뜨리지 말고" 만들어 달라고 했다.
v3 의 원칙: 시작 화면과 지도 화면을 **한 서비스처럼**, 밝고 가볍게, 숫자는 모노 글꼴, 오렌지는 신호(선택·핵심 숫자)에만.

## 결정 (사용자)

1. 범위: **시작 화면은 v3 대로 새로**, **지도 화면은 배치 유지 + 색·글꼴·로고·핀만** v3 에 맞춤
2. 예시 내용: **고른 유튜버별로 자동**, 대표 댓글은 **검증된 것만**
3. 3번 칸 지도: **실제 카카오맵**
4. 설명 문구: **넣지 않음** (제목·숫자·버튼·라벨만)

## 시작 화면 구성 (v3)

- **상단 바**: 로고(오렌지 사각 + 흰 ◆, "르슐랭 가이드") · 숫자 3개(식당·영상·댓글, 모노) · 주 버튼 "맛집 지도 보러가기 →"
- **히어로**: 작은 라벨 "유튜버 × 방문 후기 × 지도" · 큰 제목 "좋아하는 유튜버가 간 식당, **다녀왔다고 적은 사람들**은 뭐라고 했을까?"
  · 오른쪽 큰 숫자(모노, 오렌지) + "건의 방문 후기"
- **세 칸 카드** (번호 배지 1·2·3 + 칸마다 개수)
  1. 영상에서 봤다 `N편` — 영상 카드 목록: 썸네일 · 유튜버 칩 · 길이 · 르슐랭 배지(있으면) · 식당명 · 지역·분류·조회수·반응 N·쓴소리 N
  2. 다녀왔다고 적은 사람들 `N건` — 댓글 카드 목록: 좋았다는/아쉬웠다는 이야기 · 원문 · 식당·유튜브 댓글·좋아요·웨이팅 언급
  3. 지도에서 찾는다 `N곳` — 카카오맵 + 오렌지 링 핀(유튜버 얼굴) · 확대/축소
- **유튜버 고르기**: 제목 "내 유튜버를 고르세요" · "즐겨찾기 N / 3" · 칩(얼굴·이름·식당 수) · 주 버튼 "내 유튜버 맛집 지도 열기 →"
- 디자인 아래쪽 Style guide 섹션은 문서라 넣지 않는다. "카카오맵 SDK 연결 예정", "샘플" 같은 자리표시 문구도 넣지 않는다.

## 데이터 — 새 API `/api/intro`

한 번에 유튜버 10명 분을 내려 주고 화면이 고른 유튜버로 거른다(고를 때마다 서버를 다시 부르지 않게).

- 유튜버마다 식당 **2곳**: 별점 식당(RATED) · 숨기지 않은 곳 · 반응 많은 순 · **검증된 좋았던 점 댓글이 있는 곳만**
- **검증**: 대표 댓글의 출처 영상이 *한 가게만 나오는 영상*(숨긴 중복 제외)이고 또간집이 아님 — 앞서 판정한 112건에서
  여러 가게 영상 출처의 39%가 다른 가게 얘기였다. 아쉬웠던 점도 같은 기준을 통과할 때만 보여 준다.
- 식당마다: id·이름·지역·분류·좌표·반응·쓴소리·웨이팅 언급·배지 단계·유튜버, 대표 영상(id·제목·조회수·길이), 좋았다/아쉬웠다 댓글(원문·좋아요·날짜·웨이팅 언급 여부)
- 상단 숫자(식당·영상·댓글)는 `/api/seed` 메타와 같은 값
- 지금의 `/api/showcase`(복춘식당, 사람이 확인한 댓글 2건)는 **유지**하고, 성시경 식당 목록의 맨 앞에 둔다
- `/api/seed` 와 같은 CDN 캐시

## 동작

- 아무도 안 골랐으면: 저장된 선택이 있으면 그 유튜버, 없으면 **식당이 많은 유튜버 2명 + 성시경(복춘식당)** 으로 보여 준다 *(내 판단)*
- 칩을 누르면 세 칸이 그 유튜버들의 식당으로 바뀐다. 4번째는 가장 먼저 고른 사람이 빠지고, 다시 누르면 해제(지금과 같음)
- 큰 숫자 = 지금 보이는 유튜버들의 별점 식당 반응 합계 *(내 판단 — 고르면 같이 바뀌는 실제 숫자)*
- 영상 카드 → 유튜브, 댓글 카드의 "원문" → 그 영상, 지도 핀·식당명 → `/map.html?store=<id>`
- 기존 기능 유지: `lesulin.fav` 저장·미리 선택·FIFO, 데이터 오기 전·실패 시 저장값 보존, 방문 기록(`/api/track`), localStorage 차단 대응, 모바일(세 칸 세로), 숫자 하드코딩 없음
- 유튜버 얼굴은 디자인의 첫 글자 동그라미 대신 **실제 프로필 사진** *(내 판단 — 이미 있고 알아보기 쉬움)*, 선택되면 오렌지 링
- 길찾기는 디자인의 네이버 대신 **카카오** (지도 화면과 같게)
- 시작 화면 카카오맵은 지도 키를 `/api/mapkey` 로 받는다(도메인 등록됨). 지도를 못 불러오면 핀 목록만 남기고 나머지는 동작

## 지도 화면 (배치 유지)

- 색 토큰: Orange `#F2622A` · Orange soft `#FEEDE5` · Surface `#F8F6F3` · Ink `#1F1B18` · 반응 `#17806B` · 쓴소리 `#D9392B` · Sea `#B7DBEE`(쓸 곳 있으면)
- 글꼴: Noto Sans KR(300·400·500·700·900) + IBM Plex Mono(500·600) — 숫자·통계는 모노
- 로고: 오렌지 사각 + 흰 ◆ "르슐랭 가이드"(시작 화면과 같은 모양)
- 핀: 기본은 흰 링, 고른 유튜버·선택된 핀은 오렌지 링(오렌지는 신호에만)

## 하지 않을 것

- 지도 화면 배치·기능 변경 · 투표/알림/관리자 화면 디자인 변경 · 디자인의 가짜 데이터·자리표시 문구 · 설명 문장

## 확인 방법

`scripts/e2e-start.mjs` 를 v3 구조에 맞게 고치고 시나리오 추가(유튜버 바꾸면 세 칸이 바뀜 · 숫자가 API 값과 같음 ·
검증 안 된 댓글이 안 나옴 · 지도 핀 수 = 3번 칸 개수 · 모바일 넘침 없음). `scripts/check-intro.mjs` 로 API 검증.
지도 화면은 `probe.mjs` + 기존 e2e. 데스크톱·모바일 캡처로 v3 와 나란히 비교.
